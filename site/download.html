Getting started

Installed and drawing in a few minutes.

First

Install

Download the installer above and run it. GoSurvey installs to Program Files and adds a Start Menu entry. If it will not start, install the Microsoft Visual C++ Redistributable for x64.

Then

Set your units

Run UNITS once and pick the precision and bearing format you work in — surveyor's bearings, DMS or decimal. Every readout and label follows it.

Then

Bring in your data

Import points from a PNEZD CSV, linework from DXF, or raw observations from an FBK file into the Traverse Editor. Either order keeps your points.

Before you install

GoSurvey is free to install, but your browser or Windows may flag the download because the installer is not code-signed yet. Those warnings are normal — follow the steps below and you can install safely.

  1. 1
    Download the installer

    Click Continue download below. Your browser saves a file named like GoSurvey-…-Installer.exe.

  2. 2
    If your browser blocks or removes the download

    Chrome and Edge often flag an unsigned .exe with This file isn’t commonly downloaded and may discard it. Press Ctrl+J to open Downloads, find the file, and choose Keep or Keep anyway. If it was removed, open the release on GitHub, download GoSurvey-…-Installer.exe from Assets, and choose Keep when the browser warns again.

  3. 3
    If SmartScreen appears when you run the installer

    Windows may show Windows protected your PC or say the publisher is unrecognised. Click More info, then Run anyway.

  4. 4
    If the downloaded file is still blocked

    Right-click the .exe, choose Properties, check Unblock at the bottom, click OK, then run it again.

  5. 5
    Approve the installer

    Follow the setup wizard. Windows may ask for permission to install to Program Files — choose Yes. GoSurvey adds a Start Menu entry when finished.

  6. 6
    If GoSurvey will not start

    Install the Microsoft Visual C++ Redistributable (x64), then run GoSurvey again.

Every release publishes a SHA-256 checksum on GitHub so you can verify the file was not altered in transit. The checksum proves integrity; it does not remove the SmartScreen prompt.
