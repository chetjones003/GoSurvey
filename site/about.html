About GoSurvey

Survey drafting and COGO for Windows.

GoSurvey is an independent CAD platform for land surveyors, built by Chet Jones. This page explains how the application and website handle information.

Privacy policy · Effective October 24, 2026

The complete policy is also available in the GoSurvey repository.

Information the desktop app sends

Usage data

GoSurvey sends a usage ping over HTTPS on a background thread. The first ping for an installation is marked install; later launches are marked active. Each ping contains a randomly generated installation ID, event type, app version, release channel, and operating system. It contains no email or other account identity, user name, computer name, local path, drawing information, or hardware fingerprint. The ping never blocks the app. If it cannot reach the service, nothing is shown and the app continues normally. There is no in-app setting to turn it off.

The ping goes to a GoSurvey-operated Cloudflare Worker and is stored in a Cloudflare D1 database with a server timestamp, date, and country-level location derived by Cloudflare. The installation ID is random and is not based on your hardware, user name, or machine name. The Worker does not store request IP addresses, and request logging is disabled; Cloudflare may still process IP addresses and other request metadata to deliver the service.

Startup and crash diagnostics

When startup fails or the app crashes, GoSurvey automatically attempts to send a diagnostic report when it can reach the internet. Reports are stored in separate tables in the same Cloudflare D1 database. They can include the app version and channel, failure type, technical error details, stack addresses and module paths, and the local path of the diagnostic log. A local path may reveal your Windows account name or other machine-specific directory names. Reports are limited to 16 KB before sending. Diagnostic details are also appended to local logs in the GoSurvey user-data folder.

The “Send This Report” action opens a prefilled GitHub issue for you to review and submit. Review its contents before submitting.

Information kept on your device

Application preferences and the random installation ID are kept in a local gosurvey-user.json file. Previous GoSurvey versions may have saved a sign-in refresh token in Windows Credential Manager; the current application no longer reads or uses it. Startup and crash details are appended to local log files. Drawings are saved where you choose; ordinary local editing does not upload drawing files to GoSurvey.

Earlier versions also offered account sign-in and sent account details to a separate tier lookup service. The current application no longer signs in or sends new account lookups. Account records submitted by earlier versions may remain in that service; no automatic deletion schedule is established.

If you use the online map feature, GoSurvey requests map tiles from the USGS National Map service. Those requests reveal the requested map area to that service. Retrieved tiles may be cached locally.

Website and update services

The website is hosted by Cloudflare, requests release information from GitHub's public API, and loads web fonts from Google Fonts. The desktop app checks GitHub Releases for update information and downloads an installer from GitHub when you choose to update. Cloudflare, GitHub, and Google receive the request information needed to serve their services, which may include your IP address and browser or network metadata. They handle it under their own privacy terms.

Retention and privacy requests

The current telemetry database configuration does not define an automatic deletion schedule. Records remain until the operator deletes them or removes the database. Local preferences and diagnostic logs remain on your device until you delete them. GitHub, Google Fonts, Cloudflare, and the USGS may retain information under their own policies and settings.

For privacy questions or requests about GoSurvey-managed records, contact chet@gosurveycad.com.

This policy will be updated when GoSurvey's data handling changes. The effective date above identifies the current version.
