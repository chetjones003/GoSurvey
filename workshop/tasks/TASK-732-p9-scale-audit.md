# TASK-732-p9 - Automatic scale audit (REQ-395, D-2026-10-06-h)

- Status: submitted
- Requirement authority: REQ-395 (accepted), clauses 1-5; clause 6 is out of scope. Builds on REQ-394 (verdicts, best fit, `PageScale` notes) and REQ-391 clause 5 (vector line reading).
- Scope:
  - `src/pdf/PdfDimAudit` (pure): `MatchDimensions` pairs each text that reads as a length *with a unit* to the nearest axis-aligned dimension line that has an extension line at each end and a text aligned with it (greedy, closest first, one text per line); the measured span is between the two extension lines. `AuditDimensions` judges every match with REQ-394's `EvaluateCheck`, finds the consensus with `BestFitScale` (the fit without outliers, only with 5 or more matches) and lists offenders worst first. `ScaleFromConsensus` builds the scale to apply.
  - `PdfDocument::AuditPageData`: every text run (string + box) and straight stroke of a page in viewer coordinates, cancellable.
  - Viewer: **Audit scale** button next to Scale checks; dialog with progress / Cancel, counts, consensus, **Use consensus scale**, offender list (click to centre), optional full list; offenders drawn on the sheet in verdict colours.
- Assumptions (recorded, not asked): a bare number is never taken as a dimension (room numbers, grid bubbles); a text pairs only with a line of the same direction within max(18 pt, 3 x its height); an extension line is within 6 pt of the line's end along it and reaches the line within 2 pt; dimension lines drawn in pieces (broken around the text) are not joined and so are unmatched; the audit runs on the current page only.
- Verified: 9 test cases / 55 assertions (`[pdfdimaudit]`): all N matched and consensus within 0.01 %; a dimension drawn 1 % long is the one offender and does not move the consensus; unmatched text and lines; text-free page and fewer than five matches give no consensus; cancel keeps nothing; overshooting line measured between extension lines; a real generated 36 x 24 in PDF with 280 dimensions read by PDFium: read + match + audit in 0.008 s (target 5 s). Not verified by a person: the dialog and on-sheet highlights, the manual spot check on the issue's real sheet (3.9956 ft per inch; the 180.55 pt "10'-0"" span among the offenders) and the worst viewer frame during an audit (the audit runs on a worker thread, so the UI thread only polls it).
