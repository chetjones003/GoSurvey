## Implementation

- Traverse Domain owns plain `TraverseGraphNode` and `TraverseGraphGroup` values.
  Nodes retain association text/source order, ID, logical x/y, group and optional
  manual rank. Association text never replaces current measurement values.
- Commands project and serialize the exact approved `@GSTC-NODE`, `@GSTC-GROUP`
  and `@GSTC-SOURCE` grammar. Frame/source declarations are separate from command
  blocks; attached node comments still immediately precede their command after
  deterministic ordering. JSON strings preserve escaped labels and source paths.
- Parse captures valid graph metadata into project values. Canonical regeneration
  reattaches metadata by directive/relationship and repeated-observation occurrence,
  preserving IDs while measurement values change. Numeric station/set normalization
  and the first HANG's informational backsight-to-REF normalization retain identity.
- `.gstrav` version remains 1. Optional `rawSources`, project `rawSets` (separate
  from existing per-leg importer sets), and `graphLayout.nodes/groups` preserve the
  new values. Optional sourceOrder on existing stored observations retains stable
  ties across observation kinds. Missing optional fields preserve legacy v1 reads.
- Optional-field validation rejects malformed types, duplicate/invalid IDs, invalid
  faces/station/set identifiers, unknown sources, non-finite available readings,
  invalid positions/bounds/order values. Load failures leave caller data/weights
  unchanged; invalid Save data is rejected before opening the destination.
- IO uses only domain values; it does not depend on command parsing/projection.
  No UI, solver, source-file writes, dependencies or accepted format changes.
