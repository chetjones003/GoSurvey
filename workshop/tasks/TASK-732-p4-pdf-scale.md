# TASK-732-p4 - PDF page scale (REQ-390, ADR-067 addendum 2, D-2026-10-06-f)

- Status: submitted
- Requirement authority: REQ-390 (accepted, spec PR #741 merged); depends on REQ-387/388. Constraints: REQ-201 (honest reasons), REQ-300 (no new dependency).
- Scope: `src/pdf/PdfRaw` (plain-object reader/editor: object scan, page tree, reference expansion, cross-reference rebuild), `src/pdf/PdfMeasure` (units, scale maths, presets, `/VP` + `/Measure` build and parse, read and write of page scales), `AnnotSession` carries page scales (undo/redo, unsaved marker), `SaveAnnotated` writes them; viewer **Set scale...** dialog (preset, typed ratio, calibrate from two points, scope this page / every page / typed range, Clear scale) and the scale shown in the annotation row; tests `[pdfmeasure][req390][issue732]`.
- Approach: PDFium's public API cannot read or write a page's `/VP`, so the saved bytes are edited as text. After PDFium writes the file (plain objects), each changed page's object text gets a fresh `/VP` (an old one is cut out) and a new classic cross-reference table is appended, so lengths may change. Reading rewrites the file in memory through PDFium first, which turns another program's compressed object streams into plain text; only the `/VP` value is expanded (not the page's `/Parent`).
- Assumptions (flagged for manual check): `/X` carries real units per PDF point in `/C` with the unit label in `/U` (the way Acrobat/Bluebeam files read in the fixture); `/D` and `/A` are written as pass-through formats. Not yet confirmed against a real Bluebeam or Acrobat file. Existing scales are read automatically two seconds after the first page for files under 40 MB, otherwise when Set scale is opened.
- Verified: unit tests (scale maths and presets, units, `/VP` round trip, an Acrobat-style entry, bad/unknown entries refused with a reason, a compressed-style object-stream + xref-stream fixture read and rewritten, Save As round trip with scale + annotation, replace and clear, no duplicate viewport, source bytes identical, out-of-range page refused, undo/redo). Not verified by a person: the dialog and calibration on screen; the saved file in Bluebeam/Acrobat.
