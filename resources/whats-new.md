# What's New
---

## Key Features

- **Projects** — organize every drawing, point file, PDF, and cloud for one job in one place; share
  survey points across tabs; pack and email the whole project when it is ready to send
- **Coordinate systems and maps** — work in real survey zones; show USGS aerial imagery under your
  drawing and keep captured map areas with the file
- **Built-in PDF viewer** — open plan sheets inside GoSurvey, mark them up, measure, compare
  revisions, and split pages without leaving the app
- **Point clouds** — attach scan and LIDAR data, clip and style it, and use it alongside your linework
- **Piping** — lay out **pipe runs** with standard fittings from the library; export pipe geometry
  with your drawing
- **3D surfaces and grading** — build TIN surfaces, drape linework, grade side slopes to daylight,
  and model pads and solids on real ground

---

## Release Notes

**GoSurvey 0.7.0** is built around **Projects**: how you open work, share points, and deliver a job.
Everything else in this release supports that workflow — correct coordinates, maps for context,
PDFs and point clouds in the same folder, and piping where the drawing meets the field.

**Projects — the new way to work**
- Create a **project** with its own folder, settings, and shared **survey point database**
- Open several drawings on one project; points stay in sync while each drawing keeps its own
  visibility rules
- **Add drawing to project** with preview; convert units or coordinate system when needed
- Track project files (DWG, PDF, point clouds) and **pack** the project into one archive to send
- **Recent Projects** on the start screen; project health and turnover records for handoffs

**Coordinate systems and maps**
- Set and enforce a **coordinate system** for the project or drawing
- **Online map** underlays from USGS imagery, aligned to your zone
- **Capture map** areas into the drawing so the background travels with the file
- Geographic marker and geodata improve exchange with Civil 3D and GIS workflows

**PDF viewer**
- **PDFVIEW** opens sheets in a dedicated window (dockable or on a second monitor)
- Annotate, measure, set scale, overlay two revisions, and highlight changes
- Attach PDFs to a project without placing them on a layout

**Point clouds**
- Attach **E57** and other cloud formats; control density, color, and clipping
- Use clouds for context, clearance checks, and as-built comparison

**Piping and fittings**
- **PIPERUN** and related commands to route pipe with elevation and size
- Standard **fitting** blocks (flanges and library parts) for realistic layouts
- Pipe runs export to DWG with the rest of the model

**Surfaces, solids, and grading**
- Surface building, volumes, **DRAPE**, **PADSOLID**, and **GRADING** daylight lines
- Continued improvements to **3D solids**, DWG exchange, dimensions, and the in-app manual (**F1**)

See the [releases page](https://github.com/chetjones003/GoSurvey/releases) for the installer and full notes.
