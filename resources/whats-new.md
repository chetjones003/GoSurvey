# What's New
---

## Key Features

- **3D solids** — draw, fillet, chamfer, section, and check solid models; import ACIS `.sat` files
- **Full coordinate precision** — state-plane and large-coordinate work stays exact through save and reopen
- **UCS-aware editing** — move, copy, rotate, scale, mirror, stretch, offset, and array in 3D
- **In-app manual** — press **F1** for the full user guide and command reference
- **Refreshed interface** — start screen, splash, blue theme, and clearer overlapping-pick selection

---

## Release Notes

**GoSurvey 0.6.0** brings 3D solid modelling, double-precision coordinates, and a refreshed
launch experience.

**3D solids**
- New solid primitives and **FILLET**, **CHAMFER**, **SECTION**, and **SOLIDCHECK**
- Rotate, scale, and grip-edit vertices and edges; align the UCS to a solid face
- Import standalone **ACIS `.sat`** files

**Drafting and precision**
- **MOVE**, **COPY**, **ROTATE**, **SCALE**, **MIRROR**, **STRETCH**, **OFFSET**, and **ARRAY**
  work in the active UCS and 3D model space
- Coordinates stored at full double precision (±0.002 ft)
- **Quadrant** snap; **DIST** reports horizontal distance and grade

**Help and polish**
- Full user manual on **F1** / **HELP**
- Updated start screen, splash, and What's New flow
- **Save As** no longer crashes or leaves the drawing tab

See the [releases page](https://github.com/chetjones003/GoSurvey/releases) for the installer and full notes.
