# LIBEXPORT

**Command:** `LIBEXPORT`
**Category overview:** [[Import and Export]]

Writes a fitting block to its own `.dwg`, plus a `.json` metadata sidecar, for the fitting library.

`LIBEXPORT <name>[, <path.dwg>]`. Without a path it writes to the user library folder. The block must
be tagged with [[Commands/blockfitting]] first.
