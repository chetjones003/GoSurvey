# PERFHUD

**Command:** `PERFHUD` — aliases: `FRAMESTATS`
**Category overview:** [[Troubleshooting]]

Diagnostic. Toggles the frame-time overlay.

> **Status:** the command line accepts `PERFHUD` and answers "frame-time overlay ON", but this editor does not draw the overlay yet. This is a known gap.
