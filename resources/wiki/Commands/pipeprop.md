# PIPEPROP

**Command:** `PIPEPROP` — aliases: `PPROP`
**Category overview:** [[Drawing Tools]]

Changes the nominal size, and optionally the pressure class, of the selected pipe runs.

`PIPEPROP <size> [class]`, e.g. `PIPEPROP 6in CS300`.

A run is refused, and listed, when its wall would leave no bore at the new size or the new size does
not fit an existing corner. Give a thinner wall where the message asks for one.
