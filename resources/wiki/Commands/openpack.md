# OPENPACK

**Command:** `OPENPACK`
**Category overview:** [[Files and Drawings]]

Unpacks a `.gspack` file into a folder and opens the project.

> **Status:** the command line accepts `OPENPACK` and answers "choose the .gspack file to open", but this editor does not open the window yet. This is a known gap.
