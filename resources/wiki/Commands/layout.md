# LAYOUT

**Command:** `LAYOUT`
**Category overview:** [[Paper Space and Layouts]]

Manages paper layouts.

| Usage | Effect |
|---|---|
| `LAYOUT NEW [name]` | Create a layout (a taken name gets a unique variant) |
| `LAYOUT COPY [source] [new name]` | Copy a layout |
| `LAYOUT RENAME [layout] <new name>` | Rename |
| `LAYOUT DELETE [layout]` | Delete |

Without a layout name, the command acts on the current paper layout.
