# GRADINGGROUP

**Command:** `GRADINGGROUP`
**Category overview:** [[Point Groups and Surfaces]]

Collects grading results into a named group surface.

Select grading results, then:

| Usage | Effect |
|---|---|
| `GRADINGGROUP <name>` or `GRADINGGROUP <name>, Add` | Add them (creates the group) |
| `GRADINGGROUP <name>, Remove` | Remove them |
| `GRADINGGROUP <name>, List` | List the members |

Use [[Commands/volumes]] with the group for cut, fill and net.
