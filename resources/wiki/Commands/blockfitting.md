# BLOCKFITTING

**Command:** `BLOCKFITTING`
**Category overview:** [[Import and Export]]

Tags the block being edited as a piping fitting. Run inside the block editor ([[Commands/bedit]]).

Prompts for **part type**, **nominal size**, **pressure class** and **part number**; **Enter** keeps
the bracketed value. Export the tagged block with [[Commands/libexport]].
