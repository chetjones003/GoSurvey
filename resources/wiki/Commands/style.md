# STYLE


![STYLE command overview](wiki-img:commands/style.png)
**Command:** `STYLE` — aliases: `ST`, `DDSTYLE`
**Category overview:** [[Annotation]]

Text style manager: create / edit named text styles. **Modify…** opens the style editor (Font, Size, Effects and a preview).

![Modify Text Style](wiki-img:commands/modify-text-style.png)
