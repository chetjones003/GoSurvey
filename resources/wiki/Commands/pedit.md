# PEDIT


![PEDIT command overview](wiki-img:commands/pedit.png)
**Command:** `PEDIT` — aliases: `PE`
**Category overview:** [[Drawing Tools]]

Edits a polyline. A picked line or arc is converted first. Options: Close, Open, Join, Reverse, Edit vertex, Fit, Spline, Decurve. Width and linetype generation are not supported.

Works in model space and on a paper layout.
