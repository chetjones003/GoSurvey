# PASTEORIG


![PASTEORIG command overview](wiki-img:commands/pasteorig.png)
**Command:** `PASTEORIG` — aliases: `PO`
**Category overview:** [[Modify Tools]]

Paste at original coordinates

`PASTEORIG` carries selected model-space survey points with copied geometry. Point-number
collisions use **Overwrite / Renumber / Cancel**. If both drawings have defined, different
coordinate systems, paste is blocked until you choose **Convert and paste** or **Cancel**. When the
destination drawing uses shared project points, **Overwrite** replaces matching points throughout
that project; **Renumber** preserves them. The same coordinate-system and unit checks apply between
standalone drawings and across projects. Paper-space pastes do not include survey points.

See [[Modify Tools]] for related tools and workflows.
