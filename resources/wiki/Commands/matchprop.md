# MATCHPROP

**Command:** `MATCHPROP` — aliases: `MA`, `PAINTER`
**Category overview:** [[Properties]]

Copies layer, color, linetype and lineweight from one object onto others.

### Workflow

1. **Source object**: select ONE object.
2. **Destination objects**: select them, then press **Enter**.

**Esc** cancels. An object with no properties to match is refused.
