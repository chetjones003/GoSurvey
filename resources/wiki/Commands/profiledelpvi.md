# PROFILEDELPVI

**Command:** `PROFILEDELPVI`
**Category overview:** [[Alignments]]

Remove a vertical point from a design profile: PROFILEDELPVI <profile>, <station>

Removes the point at the displayed station. The removal is refused when the rest of the profile would break the curve rules, for example when the first point carries a curve. One undo restores the point.
