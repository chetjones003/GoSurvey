# PDMODE


![PDMODE command overview](wiki-img:commands/pdmode.png)
**Command:** `PDMODE`
**Category overview:** [[Drawing Tools]]

Point display mode for CAD `POINT` entities: 0 dot, 1 none, 2 plus, 3 X, 4 tick; add 32 for a circle, 64 for a square.
