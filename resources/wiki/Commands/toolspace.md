# TOOLSPACE

**Command:** `TOOLSPACE` — aliases: `TS`
**Category overview:** [[User Interface]]

Opens the Toolspace, the drawing explorer.

| Usage | Effect |
|---|---|
| `TOOLSPACE` | Open on Prospector |
| `TOOLSPACE PROJECT`, `PROSPECTOR` or `SETTINGS` | Open on that tab |
| `TOOLSPACE LIST` | List the tabs |
| `TOOLSPACE CLOSE` | Close it |

> **Status:** the ribbon's Toolspace button opens it. Typed at the command line, this editor does not
> open the panel yet. This is a known gap.
