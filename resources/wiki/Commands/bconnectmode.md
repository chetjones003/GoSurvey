# BCONNECTMODE

**Command:** `BCONNECTMODE`
**Category overview:** [[Import and Export]]

Manages smart connection modes on a port of the block being edited. Run inside the block editor ([[Commands/bedit]]).

1. **Connection point name**.
2. **Mode name**: an existing name to edit or remove, a new name to add.
3. Role, engagement length and compatibility tag for the mode; **Enter** keeps the bracketed value.
