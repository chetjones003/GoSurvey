# IMAGEATTACH

**Command:** `IMAGEATTACH`
**Category overview:** [[Point Groups and Surfaces]]

Attaches an image in model space.

`IMAGEATTACH <path>, x, y, width, height, rotation-degrees`

Width and height must be positive. The command reports the new image's ID, which
[[Commands/surfdrape]] uses.
