# SURFACELEGEND

**Command:** `SURFACELEGEND`
**Category overview:** [[Point Groups and Surfaces]]

Inserts a linked legend table for a surface analysis.

`SURFACELEGEND <surface>, ELEVATION|SLOPE|SLOPEARROW|CONTOUR|WATERSHED, x, y`

The analysis must already have computed rows on the surface.
