# SELECTSIMILAR


![SELECTSIMILAR command overview](wiki-img:commands/selectsimilar.png)
**Command:** `SELECTSIMILAR` — aliases: `SESIM`
**Category overview:** [[Object Selection]]

Right-click with something selected ▸ **Select similar**. Selects the other objects in the drawing
that match what you have picked.
