# TRAVERSE


![TRAVERSE command overview](wiki-img:commands/traverse.png)
**Command:** `TRAVERSE` — aliases: `TRAV`, `TRAVERSEEDITOR`
**Category overview:** [[Survey Points]]

Opens the Traverse Editor — compute a traverse from raw field observations (angles, distances,
vertical angles), run a least-squares adjustment, and commit the result to the drawing as survey
points. Edit it in the **Form** tab (tables) or the **Command** tab (plain text, GoSurvey's own
traverse command language), or load a field file directly: **Import .fbk…**, **Import StarNet
.dat…**, **Import RW5…** (Carlson/SurvCE/SurvPC/TDS), or **Import JobXML…**.

Full detail — every tab, table, importer, and the command language's own syntax: [[Traverse Editor]].

See [[Survey Points]] for related tools and workflows.
