# VPSCALE

**Command:** `VPSCALE`
**Category overview:** [[Paper Space and Layouts]]

Sets the scale of the current viewport.

`VPSCALE 1:20`, or `VPSCALE 50` for 50 model units per plotted inch. `VPSCALE` alone reports the
scale. Enter a viewport (MSPACE) or select exactly one viewport first. A locked viewport is refused.
