# BACTION

**Command:** `BACTION`
**Category overview:** [[Import and Export]]

Binds an action to a parameter of the block being edited. Run inside the block editor ([[Commands/bedit]]).

`BACTION <kind>, <param>[, ox, oy, dx, dy, thresh]`. Kinds: `stretch` (default), `move`, `rotate`,
`scale`, `flip`, `visibility`. See [[Commands/bparam]].
