# PROJECTSETTINGS

**Command:** `PROJECTSETTINGS`
**Category overview:** [[Files and Drawings]]

Opens Project Settings: the project's coordinate system, units and defaults.

The current drawing must belong to a project.

> **Status:** the command line accepts `PROJECTSETTINGS` and answers "Project Settings opened", but this editor does not open the window yet. This is a known gap.
