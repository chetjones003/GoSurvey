# CREATEPROFILEFROMSURFACE

**Command:** `CREATEPROFILEFROMSURFACE`
**Category overview:** [[Alignments]]

Samples a surface along an alignment and places a profile view.

`CREATEPROFILEFROMSURFACE <surface>, <alignment>, <profile name>, interval, viewX, viewY, horizontal scale, vertical scale`

The profile name must be unique. Interval and scales must be positive. Move the view later with
[[Commands/profileview]].
