# PDFSPLIT

**Command:** `PDFSPLIT`
**Category overview:** [[PDF Underlays]]

Saves chosen pages of the PDF open in the built-in viewer as a new PDF. See [[Commands/pdfview]].

> **Status:** this editor does not open the Split dialog from the command line yet. This is a known
> gap.
