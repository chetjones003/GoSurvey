# PACKPROJECT

**Command:** `PACKPROJECT`
**Category overview:** [[Files and Drawings]]

Opens Pack Project, which writes the whole project as one `.gspack` file to send.

The current drawing must belong to a project.

> **Status:** the command line accepts `PACKPROJECT` and answers "Pack Project opened", but this editor does not open the window yet. This is a known gap.
