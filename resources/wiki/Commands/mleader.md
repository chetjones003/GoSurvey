# MLEADER


![MLEADER command overview](wiki-img:commands/mleader.png)
**Command:** `MLEADER` — aliases: `ML`
**Category overview:** [[Drawing Tools]]

Draws a multileader: arrow tip, landing, then label.

Type `MSTY` (aliases `MLEADERSTYLE`, `MLSTY`) to open the active multileader style editor. It edits the
active text height, arrow size, landing gap and annotative default. Named `MLEADERSTYLE` records and
their references on new multileaders are imported from and exported to DWG. The editor currently edits
the active style only; managing and editing the full named collection is not available yet.
