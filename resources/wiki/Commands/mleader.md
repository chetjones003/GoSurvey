# MLEADER


![MLEADER command overview](wiki-img:commands/mleader.png)
**Command:** `MLEADER` — aliases: `ML`
**Category overview:** [[Drawing Tools]]

Draws a multileader: arrow tip, landing, then label.

Type `MSTY` (aliases `MLEADERSTYLE`, `MLSTY`) to open the multileader style manager, where you can set
a style current, create, modify or delete named styles. **Modify…** opens a three-tab editor (Leader
Format, Leader Structure, Content) with a preview. Named `MLEADERSTYLE` records and their references on
new multileaders are imported from and exported to DWG.
