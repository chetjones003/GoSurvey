# HELP


![HELP command overview](wiki-img:commands/help.png)
**Command:** `HELP`
**Category overview:** [[Settings and Options]]

Typing `HELP` prints a compact command list, plus notes on LINE bearing entry, ROTATE, SCALE,
INVERSE, TRIM, OFFSET, ZOOM, and OVERKILL. It is a reminder, not a reference.

Press **`F1`** anywhere to open the full in-app manual shown below — with contextual pages when
you are typing a command or hovering a ribbon control.

![In-app user manual (F1)](wiki-img:20-in-app-wiki.png)
