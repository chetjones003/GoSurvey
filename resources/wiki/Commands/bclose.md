# BCLOSE


![BCLOSE command overview](wiki-img:commands/bclose.png)
**Command:** `BCLOSE`
**Category overview:** [[Import and Export]]

Close the block editor. If a Test Block session is open, the first `BCLOSE` closes the test and returns to the editor; run `BCLOSE` again to close the editor.

See [[Import and Export]] for related tools and workflows.
