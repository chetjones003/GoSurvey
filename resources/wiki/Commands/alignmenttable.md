# ALIGNMENTTABLE

**Command:** `ALIGNMENTTABLE`
**Category overview:** [[Alignments]]

Insert a line, curve, segment or equation table: ALIGNMENTTABLE <name>, LINE|CURVE|SEGMENT|EQUATIONS[, STATIC|DYNAMIC][, <x>, <y>]

Inserts a drawing TABLE built from the alignment. LINE lists tangents, CURVE lists curves (radius, delta, length, tangent, chord, direction), SEGMENT lists every entity in travel order, and EQUATIONS lists station equations (no labelling needed). DYNAMIC (the default) rebuilds the table after every change to the alignment; STATIC is a frozen snapshot. The table sits at the point given, or at the drawing origin.
