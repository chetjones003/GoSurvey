# PIPESYS

**Command:** `PIPESYS` — aliases: `PIPENET`, `PIPINGSYSTEM`
**Category overview:** [[Drawing Tools]]

Groups pipe runs into named piping networks.

| Usage | Effect |
|---|---|
| `PIPESYS NEW <name>` | Create a network |
| `PIPESYS ADD <name>` | Add the selected pipe runs |
| `PIPESYS REMOVE <name>` | Remove the selected pipe runs |
| `PIPESYS RENAME <old name> <new name>` | Rename a network |
| `PIPESYS DELETE <name>` | Delete a network |
| `PIPESYS LIST` | List networks and their run counts |
