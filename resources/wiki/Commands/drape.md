# DRAPE

**Command:** `DRAPE`
**Category overview:** [[Point Groups and Surfaces]]

Drapes the selected lines, polylines and feature lines onto a surface.

Select the objects, then `DRAPE <surface>`. Add `, LINK` to keep them following the surface when it
is rebuilt. See [[Commands/drapelinks]].
