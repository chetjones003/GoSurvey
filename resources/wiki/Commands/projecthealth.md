# PROJECTHEALTH

**Command:** `PROJECTHEALTH`
**Category overview:** [[Files and Drawings]]

Opens Project Health: the project's linked, missing and unsaved files, to check before you pack or hand over.

The current drawing must belong to a project.

> **Status:** the command line accepts `PROJECTHEALTH` and answers "Project Health opened", but this editor does not open the window yet. This is a known gap.
