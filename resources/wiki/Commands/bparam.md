# BPARAM

**Command:** `BPARAM`
**Category overview:** [[Import and Export]]

Adds a parameter to the block being edited. Run inside the block editor ([[Commands/bedit]]).

`BPARAM <name>, <kind>[, <value>]`. Kinds: `linear` (default), `polar`, `rotation`, `flip`,
`visibility`, `move`, `lookup`. Bind actions to it with [[Commands/baction]].
