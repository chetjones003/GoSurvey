# BEDITADD

**Command:** `BEDITADD`
**Category overview:** [[Import and Export]]

Adds a line, in block-local coordinates, to the block being edited. Run inside the block editor ([[Commands/bedit]]).

`BEDITADD LINE, x1, y1, x2, y2[, visState]`. The optional visibility state shows the line only in that
state.
