# TURNOVER

**Command:** `TURNOVER`
**Category overview:** [[Files and Drawings]]

Opens Create Turnover, which records which project files were handed to whom, and when.

The current drawing must belong to a project.

> **Status:** the command line accepts `TURNOVER` and answers "Create Turnover opened", but this editor does not open the window yet. This is a known gap.
