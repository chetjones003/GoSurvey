# BSETROW

**Command:** `BSETROW <row>`
**Category overview:** [[Import and Export]]

Apply the numbered row of a block's properties table to selected block inserts. Select one or more inserts first, then enter the row number. Each selected reference is checked against its own definition; references whose definition has no such row are skipped with a message. Valid references are updated together in one Undo step.

See [[Commands/btable]] for how to create and edit rows.
