# BCONNECTEDIT

**Command:** `BCONNECTEDIT`
**Category overview:** [[Import and Export]]

Edits or removes a connection port on the block being edited. Run inside the block editor ([[Commands/bedit]]).

Name the port, then answer each prompt (role, engagement length, nominal size, compatibility tag);
the current value is shown in brackets and **Enter** keeps it. You can also remove the port.
