# LIST


![LIST command overview](wiki-img:commands/list.png)
**Command:** `LIST` — aliases: `LI`
**Category overview:** [[Drawing Tools]]

Prints type, layer, space, and geometry of the selection, or of objects picked after the command starts. Polylines include vertex count and closed/open plus first and last vertex; splines include fit and control counts; leaders include path point count and landing. Read-only — no undo entry.

Works in model space and on a paper layout.
