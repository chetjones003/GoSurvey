# ZOOMEXTENTS


![ZOOMEXTENTS command overview](wiki-img:commands/zoomextents.png)
**Command:** `ZOOMEXTENTS` — aliases: `ZE`
**Category overview:** [[Views and Navigation]]

Zoom to drawing extents: fit every object in the drawing in the view. PDF underlays are not
counted yet. In a large drawing, an object far from everything else (often a stray point at 0,0
left by an import) is left out of the fit.

See [[Views and Navigation]] for related tools and workflows.
