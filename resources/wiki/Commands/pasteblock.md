# PASTEBLOCK


![PASTEBLOCK command overview](wiki-img:commands/pasteblock.png)
**Command:** `PASTEBLOCK`
**Category overview:** [[Import and Export]]

Use `PASTEBLOCK dx, dy` to paste copied block references with an optional X and Y offset.
Nested block definitions travel with the copied references. If a definition name is already in use,
GoSurvey gives the pasted definition a unique name and keeps the existing definition in place.

See [[Import and Export]] for related tools and workflows.
