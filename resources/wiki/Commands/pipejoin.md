# PIPEJOIN

**Command:** `PIPEJOIN` — aliases: `PJOIN`
**Category overview:** [[Drawing Tools]]

Joins two pipe runs into one.

Select exactly two pipe runs and run `PIPEJOIN`. The runs must share the same nominal size and
pressure class, and exactly one coincident endpoint. The join is refused if the new corner is too
tight for the size's bend radius.
