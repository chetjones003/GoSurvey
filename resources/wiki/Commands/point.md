# POINT


![POINT command overview](wiki-img:commands/point.png)
**Command:** `POINT`
**Category overview:** [[Drawing Tools]]

Places CAD point markers. `PDMODE` and `PDSIZE` control how they are drawn. This is not a survey point — use `CREATEPOINTS` for numbered survey points.

Works in model space and on a paper layout.
