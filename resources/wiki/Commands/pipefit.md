# PIPEFIT

**Command:** `PIPEFIT` — aliases: `PFIT`
**Category overview:** [[Drawing Tools]]

Places a catalog fitting on a pipe run.

1. Select exactly one pipe run.
2. Run `PIPEFIT <part type>`. Part types: `elbow-90`, `elbow-45`, `tee`, `cross`, `reducer`, `flange`,
   `valve`, `coupling`, `cap`, `nozzle`, `other`.
3. Pick a point on the run, or type `X,Y,Z`. **Esc** cancels.

The ribbon's pipe-fitting flyout runs the same command. See [[Commands/pipepalette]].
