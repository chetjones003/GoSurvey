# PROFILEDELETE

**Command:** `PROFILEDELETE`
**Category overview:** [[Alignments]]

Delete a design profile: PROFILEDELETE <profile>

Deletes the profile and its points. One undo restores it. Deleting an alignment does not delete its profiles, so use this command to remove a profile whose alignment is missing.
