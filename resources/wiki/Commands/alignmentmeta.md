# ALIGNMENTMETA

**Command:** `ALIGNMENTMETA`
**Category overview:** [[Alignments]]

Stores named values on an alignment.

| Usage | Effect |
|---|---|
| `ALIGNMENTMETA <alignment>, SET, <name>, <value>` | Set a value |
| `ALIGNMENTMETA <alignment>, REMOVE, <name>` | Remove it |
| `ALIGNMENTMETA <alignment>, LIST` | List the values |
