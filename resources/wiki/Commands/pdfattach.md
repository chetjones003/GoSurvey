# PDFATTACH


![PDFATTACH command overview](wiki-img:commands/pdfattach.png)
**Command:** `PDFATTACH` — aliases: `PA`
**Category overview:** [[Import and Export]]

Not geometry, but it lives on the Draw ribbon: attaches a PDF page as a snappable raster underlay.
See [[PDF Underlays]].
