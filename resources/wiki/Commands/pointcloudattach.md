# POINTCLOUDATTACH

**Command:** `POINTCLOUDATTACH` — aliases: `IMPORTPOINTCLOUD`
**Category overview:** [[Import and Export]]

Imports a point cloud as reference geometry. Formats: E57, PTS, PTX, LAS, LAZ.

`POINTCLOUDATTACH "<path>"`, or `POINTCLOUDATTACH` alone to browse for the file.
