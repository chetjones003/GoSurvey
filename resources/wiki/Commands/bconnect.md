# BCONNECT

**Command:** `BCONNECT`
**Category overview:** [[Import and Export]]

Adds a connection port to the block being edited. Run inside the block editor ([[Commands/bedit]]).

Prompts, one value at a time:

1. **Port**: pick a flat solid face, or a pipe's bore or hub, or type `x,y,z,nx,ny,nz`.
2. **Connection point name**.
3. **Role**.
4. **Engagement length** (**Enter** for 0).
5. **Nominal size**, e.g. `2in` (**Enter** to skip).
6. **Compatibility tag** (**Enter** to skip).

Edit ports with [[Commands/bconnectedit]]; add connection modes with [[Commands/bconnectmode]].
