# ALIGNMENTPROPS

**Command:** `ALIGNMENTPROPS`
**Category overview:** [[Alignments]]

Alignment properties: ALIGNMENTPROPS <alignment>, NAME|DESCRIPTION|STYLE|LAYER|START, <value>

Changes one of the editable properties. The Properties panel edits the same fields. A name must be unique (any capitalisation). The style must exist. The start station cannot change while the alignment has station equations; remove them with ALIGNMENTSTATION first.
