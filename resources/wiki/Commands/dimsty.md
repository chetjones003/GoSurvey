# DIMSTY


![DIMSTY command overview](wiki-img:commands/dimsty.png)
**Command:** `DIMSTY` — aliases: `DIMSTYLE`, `DSTY`
**Category overview:** [[Annotation]]

Opens the drawing's dimension style manager. Select a named style to set it current, modify its supported
properties, or create a new named style. Style values supported by GoSurvey are saved with the drawing and
mapped to DWG `DIMSTYLE` records. The editor does not yet expose every AutoCAD dimension-style property;
unsupported units, fit, tolerance, override and compare behavior should be verified in AutoCAD.

See [[Annotation]] for related tools and workflows.
