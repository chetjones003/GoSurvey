# DIMSTY


![DIMSTY command overview](wiki-img:commands/dimsty.png)
**Command:** `DIMSTY` — aliases: `DIMSTYLE`, `DSTY`
**Category overview:** [[Annotation]]

Opens the drawing's dimension style manager. Select a named style to set it current, modify it, or
create a new named style. The editor has seven tabs (Lines, Symbols and Arrows, Text, Fit, Primary
Units, Alternate Units, Tolerances) with a live preview. Core values are saved with the drawing and
mapped to DWG `DIMSTYLE` records; the remaining settings are stored with the style in the drawing data.
Verify units, fit, tolerance, override and compare behavior in AutoCAD.

![Modify Dimension Style](wiki-img:commands/modify-dimension-style-lines.png)
