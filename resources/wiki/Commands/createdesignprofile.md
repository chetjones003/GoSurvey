# CREATEDESIGNPROFILE

**Command:** `CREATEDESIGNPROFILE`
**Category overview:** [[Alignments]]

Create an empty design profile on an alignment: CREATEDESIGNPROFILE <alignment>, <profile name>

The profile has no vertical points (PVIs) until you add them with PROFILEPVI. Names are unique within the drawing, and capitals do not matter. A read-only project refuses the command. One undo removes the profile.
