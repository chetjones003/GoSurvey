# CREATESURFACEREFERENCE

**Command:** `CREATESURFACEREFERENCE`
**Category overview:** [[Point Groups and Surfaces]]

Creates a read-only reference to a surface shared by another project drawing.

`CREATESURFACEREFERENCE <source-drawing-rel>, <source-surface-id>, <name>`

The source must be registered with [[Commands/createdatashortcut]] and have a saved, built TIN.
