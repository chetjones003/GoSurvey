# BLOCKREDEF

**Command:** `BLOCKREDEF` — aliases: `REDEFINE`
**Category overview:** [[Import and Export]]

Replaces a block definition's content with the current selection, about a new base point.

`BLOCKREDEF <name>, <baseX>, <baseY>[, <baseZ>]`. References keep their transforms.
