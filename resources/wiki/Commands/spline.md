# SPLINE


![SPLINE command overview](wiki-img:commands/spline.png)
**Command:** `SPLINE` — aliases: `SPL`
**Category overview:** [[Drawing Tools]]

Draws a NURBS spline. Fit points pass through the curve; `CV` uses control vertices. Type `Close` or `End` to finish.

Works in model space and on a paper layout.
