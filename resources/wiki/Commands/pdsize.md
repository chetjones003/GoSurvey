# PDSIZE


![PDSIZE command overview](wiki-img:commands/pdsize.png)
**Command:** `PDSIZE`
**Category overview:** [[Drawing Tools]]

Point display size for CAD `POINT` entities: 0 = 5% of the view height, negative = percent of view, positive = drawing units.
