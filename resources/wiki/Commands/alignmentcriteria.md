# ALIGNMENTCRITERIA

**Command:** `ALIGNMENTCRITERIA`  
**Category overview:** [[Alignments]]

Apply a check set to an alignment: ALIGNMENTCRITERIA <alignment>, <set>|NONE

## Notes

A road set applies to centreline, offset and curb-return alignments. A rail set applies only to rail alignments. A miscellaneous alignment takes no criteria. `NONE` removes the criteria.
