# REQ-315 / ADR-048 (GitHub #241, Phase 4 of #120) — SWEEP, end to end.
#
# BrepTests / BrepJsonTests prove the kernel (brep::Sweep, the SurfaceKind::Nurbs faces, the .gs
# round-trip). This transcript tests the half the kernel cannot: that selecting a closed profile and
# a line-or-arc path and running SWEEP puts the swept solid in the document, that its volume and
# topology are what the kernel computed, that it survives a .gs save/reopen, that one undo step
# removes it, and that a bad selection is reported rather than silently swallowed.

NEW
EXPECT SOLIDS 0

# --- A 4 x 6 closed rectangle swept along a 10-unit line -> a prism -----------------------------
# alignToPath stands the rectangle up perpendicular to the path, so V = 24 * 10 = 240.
# Area = 2*24 + perimeter(20) * 10 = 48 + 200 = 248. A box's topology: 8 v, 12 e, 6 f.
CMD POLYLINE
CMD 0,0
CMD 4,0
CMD 4,6
CMD 0,6
CMD CLOSE
ESC
CMD LINE
CMD 20,0
CMD 20,10
ESC
EXPECT POLYLINES 1
EXPECT LINES 1

BOX -2 -2 22 12
EXPECT SELECTED 2
CMD SWEEP
EXPECT SOLIDS 1
EXPECT SOLIDKIND 0 Solid
EXPECT SOLIDPROPS 0 240 248 8 12 6
EXPECT LOG "Solid created"
# the source entities are left in place
EXPECT POLYLINES 1
EXPECT LINES 1

# --- One undo step removes it; redo brings it back -------------------------------------------
CMD UNDO
EXPECT SOLIDS 0
CMD REDO
EXPECT SOLIDS 1

# --- A circle swept along a 90-degree arc -> a quarter torus --------------------------------
# tube r = 2, ring R = 15, quarter turn about (100,100). V = 30 * pi^2 = 296.0881320326807.
# Area = pi^2 * 30 (tube) + 8 * pi (two caps) = 321.220873261399.
# A circle profile is 4 v, 6 e, 4 f (the cylinder-style seam).
CMD CIRCLE
CMD 0,100
CMD 2
ESC
CMD ARC
PICK 115 100
PICK 110.6066017 110.6066017
PICK 100 115
ESC
EXPECT CIRCLES 1
EXPECT ARCS 1

BOX -5 95 120 120
EXPECT SELECTED 2
CMD SWEEP
EXPECT SOLIDS 2
EXPECT SOLIDKIND 1 Solid
EXPECT SOLIDPROPS 1 296.0881320326807 321.220873261399 4 6 4
EXPECT LOG "Solid created"

# --- A circle swept along a bulge polyline: line -> tangent 90-deg arc -> line --------------
# Segment 1: straight (0,200)->(10,200), length 10.
# Segment 2: a tangent quarter arc, radius 10 about (10,210), to (20,210).
# Segment 3: straight (20,210)->(20,220), length 10.
# V = 20*pi (the two straight tube pieces) + (pi/2)*10*pi (the elbow, Pappus) = 20*pi + 5*pi^2
#   = 112.17987473733407.
# Area = 42*pi (2 caps + 2 straight tube walls) + 10*pi^2 (the elbow wall) = 230.64293761703865.
# Three bands: 8 v, 14 e, 8 f.
CMD POLYLINE
CMD 0,200
CMD 10,200
CMD ARC
CMD 20,210
CMD LINE
CMD 20,220
CMD END
CMD CIRCLE
CMD 0,200
CMD 1
ESC

BOX -5 195 25 225
EXPECT SELECTED 2
CMD SWEEP
EXPECT SOLIDS 3
EXPECT SOLIDKIND 2 Solid
EXPECT SOLIDPROPS 2 112.17987473733407 230.64293761703865 8 14 8
EXPECT LOG "Solid created"

# --- A polyline path with a sharp corner is refused by name --------------------------------
# (Selection is cleared by the successful sweep above, so the box holds exactly these two.)
CMD POLYLINE
CMD 0,300
CMD 10,300
CMD 10,310
CMD END
CMD CIRCLE
CMD 0,300
CMD 1
ESC
BOX -5 295 15 315
EXPECT SELECTED 2
CMD SWEEP
EXPECT LOG "sharp corner"
EXPECT SOLIDS 3
ESC

# --- Solids survive a .gs save and reopen with topology intact -----------------------------
SAVEAS %OUT%/req315-sweep.dwg
OPEN %OUT%/req315-sweep.dwg
EXPECT SOLIDS 3
EXPECT SOLIDPROPS 0 240 248 8 12 6
EXPECT SOLIDPROPS 2 112.17987473733407 230.64293761703865 8 14 8

# --- SWEEP keyword options: T (twist) and A (path-alignment), REQ-315 -------------------------
# The kernel has carried brep::SweepOptions{twistRad, alignToPath} since the first sweep slice;
# these keywords are the command's way to set them. Both need the *prompted* flow — select the
# profile and path with SWEEP already running, THEN the keyword, THEN Enter — because a bare SWEEP
# on a ready selection is the build-now shortcut and uses defaults.
NEW
CMD POLYLINE
CMD 0,0
CMD 4,0
CMD 4,6
CMD 0,6
CMD CLOSE
ESC
# A 3D path with a rise: (0,0,0) -> (6,0,8), length 10, NOT perpendicular to the XY-plane profile.
CMD 3DPOLY
CMD 0,0,0
CMD 6,0,8
CMD END
ESC

# alignToPath ON (default): the rectangle stands perpendicular to the path, V = 24 * 10 = 240.
CMD SWEEP
BOX -20 -20 30 30
CMD
EXPECT SOLIDS 1
EXPECT SOLIDPROPS 0 240 248 8 12 6
CMD UNDO
EXPECT SOLIDS 0

# "A N" — fixed orientation: the rectangle is only translated along the path, giving an oblique
# prism. V = base area * perpendicular rise = 24 * 8 = 192, exactly, and different from 240 — so
# the keyword provably reached the kernel. Area 232 (48 caps + 32*2 + 60*2 slanted walls).
CMD SWEEP
BOX -20 -20 30 30
CMD A N
EXPECT LOG "align off"
CMD
EXPECT SOLIDS 1
EXPECT SOLIDPROPS 0 192 232 8 12 6
CMD UNDO
EXPECT SOLIDS 0

# "T 90" — a constant twist over the path. The prompt echoes the setting (proves the parse and the
# state write); the solid builds; BrepTests owns the twisted volume's exact value.
CMD SWEEP
BOX -20 -20 30 30
CMD T 90
EXPECT LOG "twist 90"
# A non-keyword typed at the prompt is not swallowed as an option — the twist setting stands.
CMD ZZ
CMD FOOBAR
EXPECT LOG "twist 90"
CMD
EXPECT SOLIDS 1
EXPECT LOG "Solid created"

# A twist on a curved (arc) path is refused by name — the kernel supports twist on a single
# straight segment only in this version.
CMD CIRCLE
CMD 0,100
CMD 2
ESC
CMD ARC
PICK 115 100
PICK 110.6066017 110.6066017
PICK 100 115
ESC
CMD SWEEP
BOX -5 95 120 120
CMD T 45
CMD
EXPECT LOG "single straight path"
EXPECT SOLIDS 1
ESC

CHECK ALL
