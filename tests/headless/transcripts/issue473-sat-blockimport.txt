# GitHub issue #473 — BLOCKIMPORT of a standalone ACIS .sat file (Civil 3D ACISOUT).
#
# samples/CJ_4in_WELD_NECK_FLANGE.sat is a real 4" weld-neck flange: 16 analytic faces, two of
# them planar faces pierced by an 8-bolt circle, plus a body placement transform. It must import
# as a block definition named after the file AND place its solid in the drawing (a block-stored
# solid is not yet instanced on INSERT, so direct placement is what makes the import visible).

NEW
EXPECT SOLIDS 0

DIALOG OPEN %DATA%/CJ_4in_WELD_NECK_FLANGE.sat
CMD BLOCKIMPORT
EXPECT LOG "BLOCKIMPORT — imported"
EXPECT LOG CJ_4in_WELD_NECK_FLANGE

# The solid reached the drawing, is the imported (recipe-less) kind, and the body transform put it
# where the flange lives (~4999, 4999), not at the origin where the raw ACIS geometry sits.
EXPECT SOLIDS 1
EXPECT SOLIDKIND 0 Solid
EXPECT SOLIDBOUNDS 0 4998.59457 4998.52899 0.0 4999.34457 4999.27899 0.25

# The block definition exists for reuse.
CMD BLOCKLIST
EXPECT LOG "CJ_4in_WELD_NECK_FLANGE"
