# GitHub issue #564 section 3 (D-2026-09-28-a, TASK-280): selecting shows no gizmo; 3DMOVE,
# 3DROTATE and 3DSCALE summon it for their own duration.
#
# Handle geometry is the same as req060-gizmo-translate's: a windowless run gets a 1200 x 700
# viewport at zoom 1, so a handle is 10 world units long and the grab aperture is 1 unit. The line
# (10,0)-(20,0) has its bounding-box centre, the gizmo's anchor, at (15,0,0).

# --- Acceptance 1: selecting a line, a solid, or a mix draws no gizmo ------------------------------
NEW
CMD LINE
CMD 10,0
CMD 20,0
ESC
BOX 5 -5 25 5
EXPECT SELECTED 1
EXPECT GIZMO 0
EXPECT GIZMOAXES 0
# Bare GIZMO says the persistent gizmo is off, and names the commands.
CMD GIZMO
EXPECT LOG "currently OFF"
EXPECT LOG "3DMOVE"
CHECK ALL

NEW
CMD BOX 0,0 20 10 8
CMD LINE
CMD 30,0
CMD 40,0
ESC
BOX -20 -20 45 20

# --- GIZMO MOVE still turns on the always-on gizmo, and GIZMO OFF turns it off -------------------
NEW

# --- 3DMOVE on a pre-selection: three handles, a drag commits, the command ends, one undo -----------
NEW
CMD LINE

CMD 20,0
ESC
BOX 5 -5 25 5
CMD 3DMOVE
EXPECT ACTIVE 3DMOVE
EXPECT GIZMO 1
EXPECT GIZMOAXES 3

# X handle runs (15,0,0)-(25,0,0). GRAB 5 along it, DROP 12 along it: the drag is 7.

EXPECT GIZMOAXIS 0
EXPECT LINEXYZ 0 10 0 0 20 0 0
GIZMO DROP 27 0 0
EXPECT LINEXYZ 0 17 0 0 27 0 0
# One operation per command: the commit ended it, and took the gizmo with it.
EXPECT ACTIVE NONE
EXPECT GIZMO 0
UNDO
EXPECT LINEXYZ 0 10 0 0 20 0 0
CHECK ALL

# --- 3DROTATE: three rings (D-2026-09-28-b), grab one, type the angle in degrees ------------------
# Rings are numbered by UCS axis: 0 = X red, 1 = Y green, 2 = Z blue. In plan only the Z ring is
# face-on; (15,-10,0) is on it. A quarter turn CCW about (15,0) takes (10,0) to (15,-5) and (20,0)
# to (15,5).
NEW
CMD LINE
CMD 10,0
CMD 20,0
ESC
BOX 5 -5 25 5
CMD 3DROTATE
EXPECT ACTIVE 3DROTATE
EXPECT GIZMOOP 1
EXPECT GIZMOAXES 3
# Three rings and none grabbed: a bare angle does not say which axis.
CMD 90
EXPECT LOG "click the ring to turn about first"
EXPECT LINEXYZ 0 10 0 0 20 0 0
GIZMO GRAB 15 -10 0
EXPECT GIZMOAXIS 2
CMD 90
EXPECT LINEXYZ 0 15 -5 0 15 5 0
EXPECT ACTIVE NONE
# The op the command set was for its own duration only.
EXPECT GIZMOOP 0
EXPECT GIZMO 0
UNDO
EXPECT LINEXYZ 0 10 0 0 20 0 0
CHECK ALL

# --- ESC restores the pre-command state exactly ---------------------------------------------------
# A persistent ROTATE gizmo was on before 3DMOVE; the command borrows the op and gives it back.
NEW
CMD LINE
CMD 10,0
CMD 20,0
ESC
BOX 5 -5 25 5
CMD GIZMO ROTATE
EXPECT GIZMOOP 1
CMD 3DMOVE
EXPECT GIZMOOP 0
EXPECT GIZMOAXES 3
GIZMO GRAB 20 0 0
EXPECT GIZMOAXIS 0
ESC
EXPECT LOG "3DMOVE canceled."
EXPECT ACTIVE NONE
EXPECT GIZMOAXIS -1
EXPECT LINEXYZ 0 10 0 0 20 0 0
EXPECT GIZMOOP 1
# The persistent gizmo is back, doing what it did before.
EXPECT GIZMO 1
EXPECT GIZMOAXES 3
CHECK ALL
