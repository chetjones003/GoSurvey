# A window/crossing fence must test a CURVE against the curve it draws, not against a box drawn
# round it (user report with screenshots, 2026-09-03: an orbited view, a small crossing box sitting
# in empty space clear of a circle, and the circle selects).
#
# The defect: ComputeSelectionFromRect tested a circle, an arc and an ellipse by an AXIS-ALIGNED
# BOX. That box is wrong in two directions at once, and both are user-visible:
#
#   * it reaches PAST the curve  - a circle's box is its enclosing world square, whose corners sit
#     sqrt(2)*r from the centre, so ~41% of the box lies outside the circle;
#   * it is SOLID - a circle, an arc and an ellipse are curves with nothing inside them, but a box
#     crossing-hits on any overlap, so a fence floating in the empty middle selected them too.
#
# Under an orbited camera the circle went through that box path at every angle (the plan-view path
# had already been given the real circumference test - `CircleIntersectsAABB`); arcs and ellipses
# went through it in EVERY view, plan included. Polylines with arc segments already test the arc
# they draw (REQ-316 / ADR-047, `ChainHitsRect`), so the rule this asserts is the project's own.
#
# Every MISS below is paired with a HIT at the same view angle, because a fence that selects
# NOTHING would pass every miss on its own. Each case takes a fresh drawing (NEW): a box selection
# ACCUMULATES into the current selection, so a miss run after a hit cannot be told from a hit.

# --- CIRCLE, plan view: the control. These already passed; they are here so the orbited cases
# --- below are compared against a stated answer rather than against nothing. --------------------
# Circle: centre (0,0), radius 100.

NEW
CMD CIRCLE
CMD 0,0
CMD 100
ESC
EXPECT CIRCLES 1
# Diagonally off the rim, inside the enclosing square's corner: |(75,75)| = 106 > 100, so the whole
# box lies OUTSIDE the circle. This is the shape of the reported false hit.
BOX 75 75 85 85
EXPECT SELECTED 0

NEW
CMD CIRCLE
CMD 0,0
CMD 100
ESC
# Floating in the empty middle: a circle is a curve, not a disc.
BOX -10 -10 10 10
EXPECT SELECTED 0

NEW
CMD CIRCLE
CMD 0,0
CMD 100
ESC
# Straddling the rim at (100,0) - this one MUST select, in every view below as well.
BOX 95 -5 105 5
EXPECT SELECTED 1
