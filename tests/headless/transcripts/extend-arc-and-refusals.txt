# REQ-103 step 3 (TASK-096) — EXTEND: Arc target (hand-computed boundary hit), refusal paths.
#
# Arc: 3-point semicircle, center (300,0) r=10, sweeping 180 degrees CW from (290,0) through
# (300,10) to (310,0) (identical construction to lengthen-arc-and-refusals.txt's arc, shifted +300 in
# x). Boundary VB3 is a vertical line at x=300 spanning y=-20..20, crossing the arc's full circle at
# (300,10) and (300,-10). Extending from the END (310,0, angle 0) continues the arc's own CW sense
# (decreasing angle) toward (300,-10) at angle -90 degrees — the nearer of the two crossings (90
# degrees away) vs. (300,10) at angle +90 degrees, which requires going 270 degrees around the CW
# sense to reach. So the arc's sweep grows from 180 to 270 degrees, landing its end exactly on
# (300,-10) — on the boundary.
#
# Also exercises the refusal paths (REQ-201): no-boundary-reached (a line pointed away from every
# boundary), plus Circle and closed-Polyline as EXTEND targets (both ineligible, same message set
# LENGTHEN already established, reused verbatim with cmdName="EXTEND") — geometry unchanged in every
# refusal case, never silently ignored.
# TASK-099: drives clicks with CLICK, not PICK. PICK calls SubmitViewportPick directly and
# skips the UI routing layer, which is exactly where this command was missing — the command
# ignored every real viewport click while this transcript passed green. CLICK goes through
# ViewportClickRouteFor, so an unrouted command fails here instead.
#

NEW

CMD LINE
CMD 300,-20
CMD 300,20
ESC

CMD ARC
CLICK 290 0
CLICK 300 10
CLICK 310 0
ESC

CHECK ALL
EXPECT LINES 1
EXPECT ARCS 1
SAVEAS %OUT%/extend-arc-a.dwg

CMD EXTEND
CLICK 300 0
CMD
CLICK 310 0

EXPECT LOG "EXTEND — extended to the boundary."
EXPECT ARCS 1
CHECK ALL

SAVEAS %OUT%/extend-arc-b.dwg
EXPECT DIFFERENTFILE %OUT%/extend-arc-a.dwg %OUT%/extend-arc-b.dwg

UNDO
EXPECT ARCS 1
CHECK ALL

SAVEAS %OUT%/extend-arc-c.dwg
EXPECT SAMEFILE %OUT%/extend-arc-a.dwg %OUT%/extend-arc-c.dwg

REDO
EXPECT ARCS 1
CHECK ALL

SAVEAS %OUT%/extend-arc-d.dwg
EXPECT SAMEFILE %OUT%/extend-arc-b.dwg %OUT%/extend-arc-d.dwg

ESC
