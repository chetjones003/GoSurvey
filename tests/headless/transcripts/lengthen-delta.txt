# REQ-103 step 2 (TASK-095) — LENGTHEN, DElta mode on a Line.
#
# Extends a line by +50 (click near its far end so that end is the one that moves), then shortens
# it by -20, checking the resulting length at each step via the byte-level SAMEFILE/DIFFERENTFILE
# oracle this corpus already uses (mirror-basic.txt) rather than a coordinate EXPECT verb, which
# this grammar doesn't have. LENGTHEN edits in place and allocates no new entity id per apply
# (unlike MIRROR's duplicate), so a plain pre-vs-post-undo SAMEFILE is valid here — confirmed by
# running it, not assumed.
# TASK-099: drives clicks with CLICK, not PICK. PICK calls SubmitViewportPick directly and
# skips the UI routing layer, which is exactly where this command was missing — the command
# ignored every real viewport click while this transcript passed green. CLICK goes through
# ViewportClickRouteFor, so an unrouted command fails here instead.
#

NEW

CMD LINE
CMD 0,0
CMD 100,0
ESC

CHECK ALL
EXPECT LINES 1
SAVEAS %OUT%/lengthen-delta-a.dwg

CMD LENGTHEN
CMD DE
CMD 50
CLICK 100 0

EXPECT LOG "LENGTHEN — length 100"
EXPECT LINES 1
CHECK ALL

SAVEAS %OUT%/lengthen-delta-b.dwg
EXPECT DIFFERENTFILE %OUT%/lengthen-delta-a.dwg %OUT%/lengthen-delta-b.dwg

UNDO
EXPECT LINES 1
CHECK ALL

SAVEAS %OUT%/lengthen-delta-c.dwg
EXPECT SAMEFILE %OUT%/lengthen-delta-a.dwg %OUT%/lengthen-delta-c.dwg

REDO
EXPECT LINES 1
CHECK ALL

SAVEAS %OUT%/lengthen-delta-d.dwg
EXPECT SAMEFILE %OUT%/lengthen-delta-b.dwg %OUT%/lengthen-delta-d.dwg

# Shorten by -20 (150 -> 130), still picking near the far end. DoUndo/DoRedo both cancel the
# active command deliberately (st.active = Kind::None — pre-existing behavior, not LENGTHEN-
# specific: an in-progress command could otherwise hold stale entity references across a geometry
# change), so LENGTHEN must be started again; its mode+value fields are NOT part of the undo
# snapshot and persist regardless, matching REQ-103's "mode persists across repeated picks"
# acceptance condition — only the value needs to be retyped here, not re-selecting DE itself.
CMD LENGTHEN
CMD DE
CMD -20
CLICK 150 0
ESC

EXPECT LOG "LENGTHEN — length 150"
EXPECT LINES 1
CHECK ALL
