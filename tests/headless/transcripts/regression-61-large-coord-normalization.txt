# Regression test for issue #61 — large-coordinate normalization must be IDEMPOTENT.
#
# REQ-079 as amended 2026-08-17 (decision D-2026-08-17-a): "a file at the current version loads with
# no migration OR NORMALIZATION and is byte-identical on resave."
#
# The diagnosis, confirmed rather than assumed. Issue #61 called the origin rebase a hypothesis; it
# is the cause. Loading this drawing runs MaybeRebaseLargeCoordinates, which moves
# worldDocumentOrigin from (0,0) to the extents midpoint and rebases every local coordinate:
#
#   file A:  origin (0, 0)                     local y = -999999995904
#   file B:  origin (106.625, -499999998125.5) local y = -499999995904
#
# Both describe the same drawing. So A != B is CORRECT and always will be — the rebase is the whole
# point of the local-storage design (world = local + worldDocumentOrigin), and for realistic
# state-plane data it improves precision by orders of magnitude: a 5,000 ft survey at easting 2e6
# goes from ~0.25 ft float quantization to ~0.0002 ft.
#
# What must hold is that the normalization is a ONE-TIME transformation. The second load finds the
# origin already established and does nothing, so B and C must be byte-identical. That is what this
# transcript pins, and it is what the fuzzer's oracle now checks too.
#
# Before the decision, the `gs-roundtrip` oracle compared A to B and so failed here ~1/3 of all
# seeds, which is why fuzzgen::Options::emitRoundTrip had to stay off and why every other round-trip
# defect was being buried.

NEW

# A coordinate of state-plane magnitude. 1e12 is an ordinary easting, and this project has
# worldDocumentOrigin *because* of that magnitude.
CMD LINE
CMD 0,-1e+12
CMD 213.25,-347
ESC

SAVEAS %OUT%/rt61-a.dwg

# First load: this is where the normalization happens, and it is reported rather than silent.
OPEN %OUT%/rt61-a.dwg
EXPECT LOG "Drawing origin shifted for precision"
CHECK ALL
SAVEAS %OUT%/rt61-b.dwg

# Second load: the origin is already established, so nothing moves.
OPEN %OUT%/rt61-b.dwg
CHECK ALL
SAVEAS %OUT%/rt61-c.dwg

# The load-bearing assertion: normalization converges after exactly one round trip. If it ever
# rebased twice — or rebased by a different amount the second time — this is what would catch it,
# and it would mean geometry drifting a little further on every open/save cycle.
EXPECT SAMEFILE %OUT%/rt61-b.dwg %OUT%/rt61-c.dwg
