# REQ-467 (GitHub issue #804) — DATAEXTRACTION writes the selection to a CSV file.
#
# A LINE from (0,0) to (10,0) and a POINT at (5,5) are window-selected. The typed column list
# TYPE,X,Y is answered, then the file dialog is answered with a CSV path. The LINE's X/Y is its
# first vertex (0,0), the POINT's is its own position. Rows come out in selection order.

NEW

CMD LINE
CMD 0,0
CMD 10,0
ESC

CMD POINT
CMD 5,5
ESC

BOX -1 -1 30 30 WINDOW

CMD DATAEXTRACTION
DIALOG SAVE %OUT%/dataextract-804.csv
CMD TYPE,X,Y

EXPECT LOG DATAEXTRACTION wrote 2 row(s)
EXPECT FILECONTAINS %OUT%/dataextract-804.csv "TYPE,X,Y"
EXPECT FILECONTAINS %OUT%/dataextract-804.csv "LINE,0,0"
EXPECT FILECONTAINS %OUT%/dataextract-804.csv "POINT,5,5"
