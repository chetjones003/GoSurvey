# --- GitHub issue #400 increment 4: the INTERACTIVE (picked) fill angle is measured in the UCS
# plane, not world XY -----------------------------------------------------------------------------
# User report (2026-09-08): in a FRONT UCS, picking the polar fill angle put every copy on top of
# the original. Cause: the pick's sweep angle was `atan2(worldY - centreY, worldX - centreX)`, and
# on any non-plan work plane the world-Y term is near-constant across the plane, so the angle
# collapsed to ~0 and the step angle was zero. The angle must come from the pick's position in the
# work plane's own local X/Y.
#
# Regression guard: World UCS, fill angle PICKED (not typed) at (0,10) = straight up = 90 degrees.
NEW
CMD CIRCLE
CMD 10,0
CMD 1
ESC
BOX 5 -5 15 5
EXPECT SELECTED 1
CMD ARRAY
CMD p
CMD 0,0
CMD 3
CLICKUCS 0 10
CMD y
EXPECT LOG "3 total instance(s) (polar)"
EXPECT CIRCLES 3
# 90 deg fill, n=3, partial arc => step 45 deg about world Z through the origin.
# (10,0) -> 45 deg -> (7.07107, 7.07107); -> 90 deg -> (0,10).
EXPECT CIRCLEXYZ 1 7.07107 7.07107 0 1 0 0 1
EXPECT CIRCLEXYZ 2 0 10 0 1 0 0 1
CHECK ALL
