# REQ-351 (D-2026-09-28-f, GitHub issue #564 section 4) — the whole-object Modify commands take a
# solid: COPY, MIRROR and ROTATE Copy join MOVE / ROTATE / SCALE / rectangular ARRAY (and Polar ARRAY,
# asserted in `issue400-array-solids`). Each result is a real solid — same volume and topology, and
# still a working input to a Boolean — and each operation is one undo step.

NEW

# --- COPY duplicates a solid alongside a circle, as one operation --------------------------------
# BOX centers the footprint on the given point: 20x10 at (0,0) spans X -10..10, Y -5..5.
CMD BOX 0,0 20 10 8
CMD CIRCLE
CMD 0,20
CMD 2
ESC
BOX -15 -15 15 25
EXPECT SELECTED 2
CMD COPY
CMD 0,0
CMD 100,0
ESC
EXPECT NOLOG "excluded"
EXPECT SOLIDS 2
EXPECT CIRCLES 2
EXPECT SOLIDPROPS 0 1600 880 8 12 6
EXPECT SOLIDPROPS 1 1600 880 8 12 6
EXPECT SOLIDBOUNDS 0 -10 -5 0 10 5 8
EXPECT SOLIDBOUNDS 1 90 -5 0 110 5 8
CHECK ALL
UNDO
EXPECT SOLIDS 1
EXPECT CIRCLES 1
CHECK ALL

# --- MIRROR copies a solid across the line, and the copy is a real solid -------------------------
NEW
CMD BOX 0,0 20 10 8
BOX -20 -20 20 20
EXPECT SELECTED 1
CMD MIRROR
CMD 20,-50
CMD 20,50
CMD
EXPECT NOLOG "excluded"
EXPECT SOLIDS 2
EXPECT SOLIDPROPS 1 1600 880 8 12 6
EXPECT SOLIDBOUNDS 0 -10 -5 0 10 5 8
EXPECT SOLIDBOUNDS 1 30 -5 0 50 5 8
EXPECT SOLIDKIND 1 Box
CHECK ALL
# The mirrored copy is not inside-out: it unions with a box that overlaps it by 10 in X.
CMD BOX 30,0 20 10 8
# MIRROR leaves its source selected; take it out so only the two overlapping boxes union.
BOX -20 -20 12 20 SUBTRACT
EXPECT SELECTED 0
BOX 15 -20 55 20
EXPECT SELECTED 2
CMD UNION
EXPECT SOLIDS 2
CMD SOLIDLIST
EXPECT LOG "volume 2400"
CHECK ALL

# --- MIRROR with erase-source leaves only the mirror image ----------------------------------------
NEW
CMD BOX 0,0 20 10 8
BOX -20 -20 20 20
EXPECT SELECTED 1
CMD MIRROR
CMD 20,-50
CMD 20,50
CMD y
EXPECT SOLIDS 1
EXPECT SOLIDBOUNDS 0 30 -5 0 50 5 8
CHECK ALL

# --- MIRROR of a curved solid keeps its recipe, and a mixed selection is one undo ----------------
NEW
CMD CYLINDER 0,0 5 20
CMD LINE
CMD 0,10
CMD 10,10
ESC
BOX -8 -8 12 12
EXPECT SELECTED 2
CMD MIRROR
CMD 0,-50
CMD 0,50
CMD
EXPECT SOLIDS 2
EXPECT LINES 2
EXPECT SOLIDKIND 1 Cylinder
EXPECT SOLIDBOUNDS 1 -5 -5 0 5 5 20
CHECK ALL
UNDO
EXPECT SOLIDS 1
EXPECT LINES 1
CHECK ALL

# --- ROTATE Copy keeps the original and adds the turned solid -------------------------------------
NEW
CMD BOX 0,0 20 10 8
BOX -20 -20 20 20
EXPECT SELECTED 1
CMD ROTATE
CMD 0,0
CMD c
CMD 90
ESC
EXPECT NOLOG "excluded"
EXPECT SOLIDS 2
EXPECT SOLIDBOUNDS 0 -10 -5 0 10 5 8
EXPECT SOLIDBOUNDS 1 -5 -10 0 5 10 8
EXPECT SOLIDPROPS 1 1600 880 8 12 6
CHECK ALL
