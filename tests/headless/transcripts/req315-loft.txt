# REQ-315 / ADR-048 (GitHub #241, Phase 4 of #120) — LOFT, end to end.
#
# BrepTests / BrepJsonTests prove the kernel (brep::Loft, the SurfaceKind::Nurbs faces, the .gs
# round-trip). This transcript tests the half the kernel cannot: that selecting two or more closed
# profiles at different elevations and running LOFT puts the skinned solid in the document, that its
# volume and topology are what the kernel computed, that it survives a .gs save/reopen, that one
# undo step removes it, and that a bad selection is reported rather than silently swallowed.

NEW
EXPECT SOLIDS 0

# --- Two equal circles, 8 ft apart in Z -> a cylinder, lofted -----------------------------------
# r = 5 at z = 0, r = 5 at z = 8. Volume pi*25*8 = 628.3185307179587.
# Area 2*pi*25 + 2*pi*5*8 = 157.07963267948966 + 251.32741228718345 = 408.4070449666731.
# Same topology the cylinder primitive has: 4 vertices, 6 edges, 4 faces.
CMD CIRCLE
CMD 0,0
CMD 5
ESC
CMD ELEV
CMD 8
ESC
CMD CIRCLE
CMD 0,0
CMD 5
ESC
CMD ELEV
CMD 0
ESC
EXPECT CIRCLES 2

BOX -8 -8 8 8
EXPECT SELECTED 2
CMD LOFT
EXPECT SOLIDS 1
# Issue #515 (D-2026-09-16-c): two coaxial circles loft to exactly the cylinder CYLINDER builds, and
# say so — built with analytic faces and the primitive's recipe, so SECTION and SLICE cut it alike.
EXPECT SOLIDKIND 0 Cylinder
EXPECT SOLIDPROPS 0 628.3185307179587 408.4070449666731 4 6 4
EXPECT LOG "Cylinder created"
# the source circles are left in place
EXPECT CIRCLES 2

# --- One undo step removes it; redo brings it back --------------------------------------------
CMD UNDO
EXPECT SOLIDS 0
EXPECT CIRCLES 2
CMD REDO
EXPECT SOLIDS 1

CMD 6

CMD CLOSE

CMD ELEV
CMD 0
