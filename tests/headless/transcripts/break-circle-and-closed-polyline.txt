# REQ-103 step 4 (TASK-097) — BREAK: Circle -> Arc conversion, and closed Polyline split-open
# (including the same-point "break at point" case).
#
# T6 (Circle -> Arc, hand-computed angles): Circle center (600,0) r=10. BREAK picks (610,0)
# [angle 0] then (600,10) [angle 90 deg = pi/2]. CircleBreakStartSweep removes the material CCW
# from point 1 (0 deg) to point 2 (90 deg) -- the small 90-degree wedge -- leaving an Arc that
# STARTS at point 2 (90 deg) and sweeps CCW 270 degrees back around to point 1 (360 deg = 0 deg).
# CIRCLES goes 1 -> 0, ARCS goes 0 -> 1.
#
# T8 (closed Polyline split-open): P2 is a closed rectangle (700,0)-(710,0)-(710,10)-(700,10),
# CLOSEd (4 vertices, edges each 10 long, ring length 40; edge index 3 is the closing edge
# v3->v0). BREAK picks (710,5) -- midpoint of edge 1 (v1->v2), param 15 -- then (700,5) --
# midpoint of the CLOSING edge (v3->v0), param 35. Click order matters here (closed entity):
# walking FORWARD from point 2 (700,5) wraps past v0, through v0 and v1, to point 1 (710,5) --
# a 20-unit kept span vs. the 20-unit removed span (v2, and the rest of edges 1/3) -- producing
# the 4-vertex OPEN polyline [(700,5),(700,0),(710,0),(710,5)], Closed cleared. Same id (mutated
# in place, no new entity) -- POLYLINES stays 1.
#
# T9 ("break at point" on a closed Polyline): P3 is a second closed square (750,0)-(760,0)-
# (760,10)-(750,10), CLOSEd. BREAK picks (755,0) TWICE (the same point, midpoint of edge 0) --
# point1==point2 exactly, so nothing is removed; the ring is simply re-based to start/end at that
# point, producing the 6-vertex OPEN polyline [(755,0),(750,0),(760,0),(760,10),(750,10),(755,0)]
# -- the same square outline, just opened at the pick. Same id, POLYLINES stays 1.
#
# Note: a full-circle-sweep Arc's own BREAK path (mutate in place, same id) is NOT independently
# transcript-tested here -- constructing one through the ARC command's 3-point entry within the
# 1e-4 rad "is this exactly full" tolerance is impractical by hand-picked points. It shares its
# angle math 100% with T6's Circle case (both call the same CircleBreakStartSweep), verified above;
# only the erase-vs-mutate-in-place difference is untested by transcript, reviewed by hand instead
# (task log).
