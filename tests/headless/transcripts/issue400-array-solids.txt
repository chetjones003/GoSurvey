NEW

# --- Rectangular ARRAY duplicates a solid alongside an ordinary line ------------------------------
CMD BOX 0,0 20 10 8
EXPECT SOLIDS 1
EXPECT SOLIDPROPS 0 1600 880 8 12 6
CMD LINE
CMD 0,20
CMD 10,20
ESC
BOX -5 -5 25 25
EXPECT SELECTED 2
CMD ARRAY
CMD r
CMD 2
CMD 100
CMD 1
CMD 0
CMD
EXPECT LOG "2 total instance(s) (2 x 1)"
EXPECT LINES 2
EXPECT SOLIDS 2
EXPECT SOLIDPROPS 0 1600 880 8 12 6
EXPECT SOLIDPROPS 1 1600 880 8 12 6
# It really moved: the original box's bounds are untouched, and the copy sits 100 further in X.
# BOX centers the footprint on the given point: 20x10 at (0,0) spans X -10..10, Y -5..5.
EXPECT SOLIDBOUNDS 0 -10 -5 0 10 5 8
EXPECT SOLIDBOUNDS 1 90 -5 0 110 5 8
CHECK ALL

# --- Undo removes the generated solid instance in one step -----------------------------------------
UNDO
EXPECT SOLIDS 1
EXPECT LINES 1
CHECK ALL
