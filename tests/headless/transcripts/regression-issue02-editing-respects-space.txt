# Issue 02 — OVERKILL reached into model space from a paper sheet.
#
# Run from a layout, OVERKILL ignored the sheet's duplicates (the only geometry on screen, and the
# reason the user ran it), rewrote every model line's elevation in a space that was not visible, and
# reported "nothing to clean up" — which was accurate about neither.
#
# Drawing and editing commands route by space. OVERKILL cleans only the active sheet; JOIN remains
# model-only. This checks that cleaning sheet geometry leaves the model geometry untouched.

NEW
CMD ELEV 286.715
CMD LINE
CMD 0,0
CMD 100,0
ESC
CMD LINE
CMD 0,50
CMD 100,50
ESC
EXPECT LINES 2
EXPECT ELEVATION LINE 0 286.715

SPACE PAPER

# --- OVERKILL cleans duplicate geometry on the active paper layout ------------------------------
CMD LINE
CMD 0,0
CMD 10,0
ESC
CMD LINE
CMD 0,0
CMD 10,0
ESC
EXPECT PAPERLINES 2
CMD OVERKILL
EXPECT PAPERLINES 1
EXPECT LOG "cleaned up 1 object"

SPACE MODEL

# The whole point: the model drawing is exactly as it was. Before the guard, OVERKILL alone would
# have left both of these at 0 while claiming it had done nothing.
EXPECT LINES 2
EXPECT ELEVATION LINE 0 286.715
EXPECT ELEVATION LINE 1 286.715
EXPECT VERTEX LINE 0 0 0 0 286.715
EXPECT VERTEX LINE 1 1 100 50 286.715

# And it still works where it IS available.
CMD OVERKILL
EXPECT LINES 2
EXPECT ELEVATION LINE 0 286.715

CHECK ALL
