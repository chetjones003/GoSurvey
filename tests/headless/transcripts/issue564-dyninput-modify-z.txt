# The section's acceptance names these commands: "In MOVE (and LINE, COPY, PIPERUN, …), typing @
# visibly switches the boxes to ΔX/ΔY". A typed Z is read at every point prompt (D-2026-09-28-j).

# --- MOVE, plan view: two boxes, `@` → ΔX ΔY from the base point ------------------------------------
