# Section coverage across every 3D primitive (2026-09-22, asked for from the app: "test all of the
# other 3d objects to see if they get sectioned correctly").
#
# One block per primitive per cut — level, vertical and 45 degrees, each through the middle of the
# solid. It pins the whole matrix in one place: what sections, what is refused, and in which words,
# so a change to any recogniser has to come and say so here.
#
# The SHAPES are held to their analytic sizes in BrepTests: [sectioncoverage] covers the wedge,
# pyramid and polysolid; [issue517] and [issue520] the cylinder, cone, sphere and torus. This is
# about the COMMAND answering, for each solid, at each angle.
#
# The 45-degree cut of a cylinder or cone is refused here because these solids are short: the cut
# runs off the end. A cylinder tall enough for the cut to stay between its caps says "this cut is an
# ellipse" instead (issue516-section-refusal-reasons).

# --- a box, cut level --------------------------------------------------------
NEW
CMD BOX 0,0,-25 100 70 50
BOX -300 -300 300 300
CMD SECTION
CMD UCS
EXPECT LOG "SECTION — 1 section outline created. The solid is unchanged."
EXPECT POLYLINES 1
EXPECT SOLIDS 1
CHECK ALL

# --- a box, cut vertical -----------------------------------------------------
NEW
CMD BOX 0,0,-25 100 70 50
CMD UCS
CMD X
CMD 90

CMD SECTION
CMD UCS
EXPECT LOG "SECTION — 1 section outline created. The solid is unchanged."
