# --- COPY under a tilted UCS: the duplicate carries the 3D delta ---------------------------------
# UCS X 90; a circle drawn at UCS (0,0) = world origin, radius 2. COPY base UCS (0,0), destination
# UCS (0,10) => the copy sits at world (0,0,10). The original stays put.
NEW
CMD UCS
CMD X
CMD 90
CMD CIRCLE
CLICKUCS 0 0
CMD 2
ESC
BOX -5 -5 5 5
EXPECT SELECTED 1
CMD COPY
CLICKUCS 0 0
CLICKUCS 0 10
ESC
CMD UCS
CMD W
EXPECT CIRCLES 2
EXPECT CIRCLEXYZ 0 0 0 0 2 0 -1 0
EXPECT CIRCLEXYZ 1 0 0 10 2 0 -1 0
CHECK ALL
